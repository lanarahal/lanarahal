- **Contact** — message form → lanarahal576@gmail.com

## Setup on GitHub Pages

1. Create a new public repository (e.g. `lanarahal` or `lanarahal.github.io`)
2. Upload all files from this folder
3. Add secret `HELIUS_API_KEY` (free from https://dev.helius.xyz)
4. Enable GitHub Pages (Settings → Pages → Deploy from branch `main` / root)
5. Run the Action once manually (Actions tab → Check for new Mini Toads → Run workflow)

## Contact form (Formspree)

1. Go to https://formspree.io → free account
2. Create a form and set the email to `lanarahal576@gmail.com`
3. Copy the form ID (looks like `https://formspree.io/f/xxxxxxxx`)
4. Open `contact.html` and replace `YOUR_FORM_ID` with your real ID
